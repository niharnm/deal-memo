---
description: Use when writing or rewriting the final investment memo for a startup.
---

Write the memo in this exact markdown structure. Keep each section tight.

# {Company} Investment Memo

**One-liner:** what the company does, for whom, in one sentence.
**Website:** link | **Stage:** best estimate with source | **HQ:** city

## Snapshot

| Signal | Score (1 to 5) | Why |
| --- | --- | --- |
| Team | | |
| Market | | |
| Product and differentiation | | |
| Traction | | |
| Overall | | |

Scoring guide: 5 = top decile for the stage, 3 = typical, 1 = clear gap. Overall is a judgment, not an average.

## Team
Founders and key people, prior roles, why they win this market. Cite sources.

## Market
Market definition. Top-down size and a simple bottom-up estimate (show the math: customers x price). Why now.

## Competition
Table: Competitor | Funding | Positioning | How this company differs. Then two or three sentences on defensibility.

## Traction
Funding history table (Round | Date | Amount | Lead), then other public signals: hiring, customers, launches, press.

## Bull case
Three bullets.

## Risks
Three to five bullets, each with what would de-risk it.

## Questions for the founders
Five sharp diligence questions this research could not answer.

## Recommendation
One of: **Take the meeting**, **Track**, or **Pass**, with a two-sentence rationale (labeled as judgment).

## Sources
Numbered list of every link cited above.
